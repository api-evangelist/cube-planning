# Cube (Cube Planning)

> Cube is a financial planning & analysis (FP&A) platform — an "agentic finance layer" that gives finance teams clean, decision-ready data across their tool stack. Its REST API (OAuth 2.0, 296 operations) exposes dimensions, formulas, data tables, cube data exports, dashboards, connections, tags, and company/user administration. This llms.txt was generated by the API Evangelist enrichment pipeline from the provider's public OpenAPI and site.
